# Луксмаксинг Симулятор 2 — 3D (Kotlin)

3D-игра в открытом мире на чистом Kotlin + OpenGL ES 2.0 (без движков и библиотек).

## Как собрать APK
**Вариант 1 — Android Studio:** открыть папку проекта → дождаться синхронизации → Build → Build APK(s).

**Вариант 2 — GitHub Actions (APK сам попадёт в Releases):**
залить все файлы в `kochvalds/kochbratangame2` (ветка `main`). Workflow `.github/workflows/build.yml`
соберёт APK и создаст релиз с файлом `LooxmaksingSimulator2.apk`.
Нужно: Settings → Actions → General → Workflow permissions → Read and write.

## Управление
- левая половина экрана — стик (движение / газ-руль в машине), полный наклон = бег
- правая половина — вращение камеры
- ДЕЙСТВИЕ — сесть/выйти из машины, войти в здание, говорить с людьми
- ОГОНЬ, ПРЫЖОК, ОРУЖ. (смена оружия); в машине ОГОНЬ/ПРЫЖОК = РУЧНИК (дрифт)
- МЕНЮ (или кнопка «Назад») — внешность, прокачка, достижения, оружие, статистика, сохранение

## Что есть
Город 1200×1200 м, день/ночь, 70 машин 5 типов с физикой (сцепление, дрифт, крен, повреждения),
баня «Парок» (пар, веник, диалоги, Дядя Миша, Колян, Кочбратан), спортзал «Железо»
(жим, бег, мьюинг у зеркала, мышцы растут визуально), магазин одежды, оружейный «Калибр»,
гопники, оружие, деньги, уровни и 5 навыков, 19 достижений, автосохранение.
